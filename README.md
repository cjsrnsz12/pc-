# 어비스 헬퍼 PC

마비노기 모바일의 화면을 인식해 입장·전환·보상 처리를 돕는 Windows 10/11용 앱입니다. 게임 화면의 실제 내용 영역은 **가로 800 × 세로 1000**으로 사용합니다.

## 다운로드 및 실행

1. [최신 배포](https://github.com/cjsrnsz12/pc-/releases/latest)에서 **AbyssHelper.exe**를 내려받습니다.
2. 실행 파일을 더블클릭합니다. 별도의 Python 설치나 CMD 창이 필요하지 않습니다.
3. 게임을 실행하고 앱이 마비노기 모바일 창만 찾아 자동 선택합니다.
4. **게임 창 자동 맞추기**를 누르고 목적지·난이도를 선택합니다.
5. **시작(F8)**을 누른 뒤 게임 창을 클릭합니다. 중지는 **F9**입니다.

게임 화면이 다른 창에 가려지지 않도록 배치하세요. 다른 앱으로 전환하면 인식과 입력을 보류하고, 게임으로 돌아오면 이어갑니다. 최소화·크기 변경·창 종료 시에는 중지합니다. UI 크기·레이아웃이 참고 이미지와 달라 인식되지 않으면 기록에 안내하고 입력을 보류합니다.

게임 창 자동 맞추기는 클릭할 때마다 게임을 다시 검색하고, 최소화·최대화 상태를 복원합니다. 전체 화면이면 게임 활성화 후 Alt+Enter를 한 번 보내 전환을 시도하고, 상태를 다시 읽어 필요하면 창 스타일을 보정한 뒤 실제 내용 영역을 800×1000으로 맞춥니다. 제목 표시줄까지 넣을 공간이 없으면 테두리 없는 800×1000 창으로 맞춥니다. 크기를 다시 측정해 최대 3회 보정합니다. 실패하면 모니터 공간 부족, Windows 오류, 게임의 화면 모드 고정 여부를 안내하고 현재 크기·DPI·스타일을 app.log에 기록합니다. 게임이 독점 전체 화면 전환을 지원하지 않거나 해상도를 계속 되돌리면 자동 적용을 보장할 수 없습니다. 여러 게임 창이 있으면 목록에서 고른 창을 유지합니다. 게임 제목이 `마비노기 모바일` 또는 `Mabinogi Mobile`인 창만 대상으로 하며 브라우저·일반 마비노기·런처·문서 창은 제외합니다.

## 구현된 순서

- 일반 화면: 이동하지 않는 상태를 연속 4초 확인 → 메뉴 → 어비스 → 목적지 이름을 찾아 클릭.
- 입장 설정: 던전 이름 → 함께하기 선택 → 선택 난이도 → 우연한 만남 초록색 ON 확인 → 입장하기.
- 이미 켜진 우연한 만남을 다시 누르지 않습니다. 확인되지 않은 조건에서는 입장하지 않습니다.
- 입장 대기 및 검은 로딩 화면에서는 메뉴를 열지 않습니다.
- 전투 도중 시작해도 스킬 UI가 확인되면 전투 상태를 유지합니다. 전투에서 잠깐 멈춰도 메뉴를 열지 않습니다.
- 장면 넘기기 버튼 → 한 번 클릭 → 보스 전투.
- 던전 클리어와 화면 터치 안내가 모두 나타나면 중앙 한 번 클릭.
- 보상 화면에서 솔로 반복 설정이 켜져 있으면 다시 하기. 꺼져 있으면 보상에서 대기.
- 우연한 만남 대기부터 로딩 완료까지 던전 입장 중으로 유지.
- 협동 미션 완료창은 확인을 누르고 기존 진행 상태를 유지.
- 음식 아이콘이 나타나면 한 번 클릭. 아이콘이 사라질 때까지 중복 클릭하지 않습니다.
- 일반 버튼은 반응이 없으면 2.5초 간격으로 최대 3회 시도한 뒤 중지. 중앙 클릭·장면 넘기기·음식은 한 번만 클릭합니다.

목적지는 허상의 정박지·광기의 동굴·흩어진 물길입니다. 허상의 정박지 기본 난이도는 매우 어려움이며 매우 어려움2와 구별합니다. 다른 두 던전의 기본값은 제공된 목록 화면을 따라 어려움·입문으로 두었고 앱에서 바꿀 수 있습니다. 함께하기 설정과 솔로 반복 체크는 별개로, 솔로 반복은 사용자의 PC에서 다시 하기를 누르는 기능입니다.

## 업데이트 안내

앱 시작 시, 실행 중 30분마다, 또는 업데이트 확인 버튼으로 이 저장소의 **정식 GitHub Release**를 확인합니다. 실행 파일이 첨부된 더 높은 버전만 안내합니다. 별도 안내 창에 변경 내용을 표시합니다. **새 버전 다운로드**를 누르면 앱 안에서 저장 위치를 선택하고 실행 파일을 직접 내려받을 수 있습니다. 진행률·용량 표시, 취소·재시도 및 저장 폴더 열기를 지원합니다. 크기·실행 파일 형식과 제공되는 SHA-256 정보를 확인한 뒤 저장하며 실패한 부분 파일은 정리합니다. 창의 X 또는 닫기로 닫을 수 있습니다. 다운로드 후 기존 앱을 종료하고 새 실행 파일로 교체하세요. 자동 설치나 파일 강제 교체는 하지 않습니다.

네트워크 연결 없이도 앱의 기본 동작은 사용할 수 있습니다. 저장소가 공개되어 있으므로 사용자의 GitHub 로그인·토큰을 앱에 저장하지 않습니다.

## 기록과 설정

`%LOCALAPPDATA%\AbyssHelper`에 설정과 실행 기록을 저장합니다. 앱의 **기록 폴더** 버튼으로 열 수 있습니다. 로그는 순환 저장하며 게임 화면이나 채팅 이미지를 업로드하지 않습니다.

## 검증 범위

제공된 스크린샷에 대한 화면 분류와 상태 전환 단위 테스트를 포함합니다. Windows 빌드에서는 생성된 EXE의 GUI 서브시스템과 시작·UI·참고 이미지 로딩을 검사합니다. 실제 게임에서의 인식률, 특정 캐릭터의 대기 모션, 게임의 입력 허용 여부는 사용자의 PC에서 확인이 필요합니다. 화면의 정지 여부는 캐릭터 발밑과 주변 영역의 영상 변화로 추정합니다.

이 버전은 안내된 UI 흐름을 자동화합니다. 이동·몬스터 탐색·별도 스킬 입력·부활은 아직 구현하지 않았으며 게임의 자동 전투 기능을 사용합니다. 광기의 동굴·흩어진 물길의 상세 화면은 제공되지 않아 인식 조정이 추가로 필요할 수 있습니다. 던전 이름을 확인하지 못하면 입장을 보류합니다.

## 개발 및 빌드

Python 3.12를 권장합니다. `python -m pip install -r requirements.txt`, `python -m pip install pytest pyinstaller==6.16.0` 후 `python -m pytest -q`로 테스트합니다. Windows에서 `python build_windows.py`로 `dist/AbyssHelper.exe`를 생성합니다. 소스 실행은 `pythonw Start.pyw`를 사용하면 콘솔이 없습니다.

GitHub Actions가 main의 `version.py` 변경 또는 수동 실행 시 테스트 → Windows EXE 생성 → GUI 시작 검증 → Release 발행을 진행합니다. 다음 배포에서는 `version.py`, `version_info.txt`, `CHANGELOG.md`, `latest.json`의 버전을 함께 올리세요. 동일 태그의 배포는 덮어쓰지 않습니다. `latest.json`은 외부 연동용 정보이며 앱의 실제 업데이트 판단은 바이너리가 올라온 정식 Release를 기준으로 합니다.
